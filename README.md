# SPV Super Bazar 🛒

A fast, modern, quick-commerce web application inspired by **Swiggy Instamart**, built for **SPV Super Bazar** (Ramavaram / Kutukuluru, East Godavari).

---

## ✨ Features

- **⚡ Instamart Quick-Commerce UI/UX**:
  - Ultra-clean, modern grocery catalog with custom product shelves and category grids.
  - High-precision Gilroy typography and curated **Emerald Green 700** (`#047857`) brand palette.
  - Dual auto-sliding hero banners with responsive crop alignments.
- **🛒 WhatsApp Checkout Integration**:
  - Direct WhatsApp order generation with formatted item summaries, quantities, and customer delivery address details.
  - Interactive item quantity steppers and cart drawer.
- **📍 Live Address Detection & Geocoding**:
  - Real-time address autocomplete powered by OpenStreetMap (Nominatim Geocoding API) with zero API keys required.
  - One-tap GPS reverse geocoding to detect current village/street location.
- **📱 100% Mobile & Desktop Responsive**:
  - Tailored mobile 3-tab bottom navigation (`Home`, `SPV Super Bazar`, `Categories`).
  - Mobile slide-up sticky cart summary bar and responsive desktop single-row header.
  - Zero horizontal overflow shift across all viewport sizes.

---

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Typography**: Gilroy (Geometric Sans-Serif)
- **Icons**: [Lucide React](https://lucide.dev/)
- **State Management**: React Context API (`CartContext`)

## 🚀 Getting Started

### 1. Prerequisites
- **Node.js** (v18 or higher)
- **npm** or **yarn** / **pnpm**

### 2. Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/Charantej111/SVP.git
cd SVP
npm install
```

### 3. Running Locally
Start the development server:
```bash
npm run dev
```
Open [http://127.0.0.1:5173/](http://127.0.0.1:5173/) in your browser.

### 4. Production Build
Compile and bundle for production:
```bash
npm run build
```
Preview the production build locally:
```bash
npm run preview
```
